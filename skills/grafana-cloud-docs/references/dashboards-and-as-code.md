## Design and sprawl

- Never copy a dashboard to change parameters: link to the master with `var-<name>=value`. If a copy is unavoidable, rename it and drop the tags. Put `TEST` or `TMP` in the name of temporary ones (or prefix `TEST:`) and delete them when done.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/build-dashboards/best-practices/
- Make the data source a variable. Normalize axes (CPU in percent). Turn stacking off in most cases. No refresh faster than the data changes.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/build-dashboards/best-practices/
- Target maturity: JSON in version control, generated by code, no browser editing.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/build-dashboards/best-practices/

## Variable syntax

- `${var}` inside words, `${var:format}` for multi-value formatting. An invalid format silently falls back to `glob`.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/variables/variable-syntax/
- Formats for `test1, test2`: `csv` -> `test1,test2`, `pipe` -> `test1|test2`, `json` -> `["test1", "test2"]`, `singlequote` -> `'test1','test2'`, `sqlstring` doubles quotes, `queryparam` -> `var-servers=test1&var-servers=test2`, `raw` skips data source-specific formatting.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/variables/variable-syntax/

## Variable behavior

- No default value: the top entry is preselected. For an empty default, tick Include All with custom all value `.+`.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/variables/add-template-variables/
- Include All with a blank custom value concatenates every value (can cause performance problems). The custom all value is never escaped.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/variables/add-template-variables/
- Include All + Display "Hidden" selects only the first value unless All was saved while visible.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/variables/add-template-variables/
- Refresh "On dashboard load" blocks loading. Use "On time range change" only for time-dependent queries. Custom variables for fixed values, Text box for high cardinality.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/variables/add-template-variables/
- Data sources auto-escape values. Avoid it with `${var:raw}`. `${query0.0}` is the first element.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/variables/add-template-variables/
- Grafana 13.1 renamed "Ad hoc filters" to "Filter and Group by". The schema kind stays `AdhocVariable`.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/variables/add-template-variables/

## Built-in variables

- `$__from`/`$__to` are epoch ms. `${__from:date:iso}` is ISO UTC, `:date:seconds` epoch s.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/variables/built-in-variables/
- `$__range*` only for Prometheus and Loki, `$__rate_interval` only for Prometheus.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/variables/built-in-variables/
- `$__url_time_range` gives `from=<ms>&to=<ms>`, add the separator yourself: `https://host/d/abc?${__url_time_range}`.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/variables/built-in-variables/
- `$__namespace` is `stacks-<id>` on Cloud, interpolated only in dashboards.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/variables/built-in-variables/

## Query options and expressions

- Max data points defaults to panel width: resizing or View mode changes the data, reducers and expressions. Set a fixed Max data points or Min interval for stable values.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/panels-visualizations/query-transform-data/
- Relative time and time shift are ignored on an absolute dashboard range. Shift by `1M/M`, not `1M`. Hidden queries are not sent.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/panels-visualizations/query-transform-data/
- Expressions copy data to the server: process in the data source when possible. Reference queries as `$A`.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/panels-visualizations/query-transform-data/expression-queries/
- Math on 2 series evaluates only shared timestamps: Resample first. One data source without data makes the whole result `NoData`. Sum of empty = 0, Last of empty = NaN.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/panels-visualizations/query-transform-data/expression-queries/
- SQL queries combined by expressions need identical timestamps: `SELECT 1 AS "time"`, not `NOW()`.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/panels-visualizations/query-transform-data/expression-queries/

## JSON model and dashboard API

- Schemas: V2 Resource (current), V1 Resource (`apiVersion: dashboard.grafana.app/v1` with `metadata` and `spec`), Classic. Classic `uid` is 8-40 chars, `id` is `null` until the dashboard is first saved. `gridPos.w` 1-24, `h` in 30 px units.
  https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/dashboards/build-dashboards/view-dashboard-json-model/
- API `/apis/dashboard.grafana.app/v1/namespaces/:namespace/dashboards[/:uid]` (`:namespace` is `stacks-<id>` on Cloud, see `$__namespace`) with `Authorization: Bearer <SERVICE_ACCOUNT_TOKEN>`.
  https://grafana.com/docs/grafana-cloud/learn-and-build/developer-resources/api-reference/http-api/dashboard/
- Create: `metadata.name` is the UID (`metadata.generateName` for random), folder in annotation `grafana.app/folder`, JSON in `spec`. 409 = exists.
  https://grafana.com/docs/grafana-cloud/learn-and-build/developer-resources/api-reference/http-api/dashboard/
- Update and delete use `metadata.name`, never `metadata.uid`. Commit message in `grafana.app/message`. 409 = a dashboard with the same version already exists.
  https://grafana.com/docs/grafana-cloud/learn-and-build/developer-resources/api-reference/http-api/dashboard/
- List with `limit` and `continue` until no `metadata.continue` comes back.
  https://grafana.com/docs/grafana-cloud/learn-and-build/developer-resources/api-reference/http-api/dashboard/

## As-code tooling

- Default: Terraform for the broadest coverage. Foundation SDK to generate dashboards. Git Sync for Git round-trips.
  https://grafana.com/docs/grafana-cloud/learn-and-build/as-code/terraform/
- Cloud stack: one provider alias with `cloud_access_policy_token` creates `grafana_cloud_stack` and its service account token. A second with `url = grafana_cloud_stack.my_stack.url` manages in-stack resources. Set `delete_protection = true`.
  ```hcl
  resource "grafana_dashboard" "dashboard" {
    provider    = grafana.my_stack
    config_json = file("<file-name>.json")
  }
  ```
  https://grafana.com/docs/grafana-cloud/learn-and-build/as-code/terraform/terraform-cloud-stack/
- Foundation SDK: typed builders (Go, TypeScript, Python, PHP, Java), errors are caught at compile time, then `build()` produces the final dashboard.
  ```
  const builder = new dashboard.DashboardBuilder('My Dashboard')
    .withPanel(new timeseries.PanelBuilder().title('Random Time Series').datasource(testdataRef));
  const dashboard = builder.build();
  ```
  https://grafana.com/docs/grafana-cloud/learn-and-build/as-code/foundation-sdk/
- Git Sync: bidirectional. Each repository resource syncs one location (repository, branch and path), and several instances can sync different branches or paths of the same repository. Titles come from the JSON, not file names. `_folder.json` keeps a folder's UID across renames.
  https://grafana.com/docs/grafana-cloud/learn-and-build/as-code/git-sync/key-concepts/
- File provisioning (`Repository` with `type: local`) is self-managed only, never Cloud.
  https://grafana.com/docs/grafana-cloud/learn-and-build/as-code/provision-resources/
