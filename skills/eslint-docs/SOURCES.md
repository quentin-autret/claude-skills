## Not crawled

- `contribute/`, `maintain/` and `library/`: about the ESLint project itself, not about using it.
- Migration guides to versions 1 through 8: obsolete.
- The rule index page is a template over rule metadata: the recommended, fixable and deprecated flags are not in the raw pages, so no reference file lists the full recommended set.
