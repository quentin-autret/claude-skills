## Install pattern for every plugin

- `npm run tauri add <name>` adds the plugin dependency (the Automatic setup tab). Manual: `cargo add tauri-plugin-<name>`, `.plugin(tauri_plugin_<name>::init())` (sql, store, log and stronghold use `Builder`; autostart's `init` takes arguments), npm `@tauri-apps/plugin-<name>`. https://v2.tauri.app/plugin/autostart/
- Dangerous commands and scopes are blocked until a capability allows them. https://v2.tauri.app/plugin/autostart/
- With `"withGlobalTauri": true` the API is on `window.__TAURI__.<plugin>` (for example `window.__TAURI__.fs`; the namespace can differ, e.g. `clipboardManager`). https://v2.tauri.app/plugin/file-system/ https://v2.tauri.app/plugin/clipboard/
- Desktop-only plugins: target-gated dependency, registered in `setup` under `#[cfg(desktop)]`. Mobile-only: `cfg(any(target_os = "android", target_os = "ios"))` and `#[cfg(mobile)]`. https://v2.tauri.app/plugin/autostart/ https://v2.tauri.app/plugin/positioner/ https://v2.tauri.app/plugin/barcode-scanner/

```sh
cargo add tauri-plugin-positioner --target 'cfg(any(target_os = "macos", windows, target_os = "linux"))'
```

```rust
.setup(|app| {
    #[cfg(desktop)]
    app.handle().plugin(tauri_plugin_positioner::init());
    Ok(())
})
```

https://v2.tauri.app/plugin/positioner/

## fs (file system)

- In Rust, use `std::fs` / `tokio::fs`. The plugin's Rust side only adjusts scopes: `app.fs_scope().allow_directory("/path", false)` via `FsExt`. https://v2.tauri.app/plugin/file-system/
- Paths must be relative to a base directory or built with the path API; `../` is rejected. https://v2.tauri.app/plugin/file-system/

```js
import { readFile, BaseDirectory } from '@tauri-apps/plugin-fs';
const contents = await readFile('avatars/tauri.png', { baseDir: BaseDirectory.Home });
```

https://v2.tauri.app/plugin/file-system/

- Most fs commands need a scope too: `fs:allow-exists` alone fails with `forbidden path`. https://v2.tauri.app/plugin/file-system/

```json
{ "identifier": "fs:allow-exists", "allow": [{ "path": "$HOME" }, { "path": "$HOME/**/*" }] }
```

https://v2.tauri.app/plugin/file-system/

- Permission names are generated per command: `allow-<command>` / `deny-<command>` in kebab case (`fs:allow-read-text-file`, `fs:allow-write-text-file`), plus scope sets per base directory such as `fs:allow-resource-read-recursive`. The full list is the plugin's permission table, or `permissions/autogenerated/` in its source. https://v2.tauri.app/learn/security/using-plugin-permissions/ https://v2.tauri.app/develop/resources/ https://v2.tauri.app/develop/plugins/

```json
"permissions": ["core:default", "fs:allow-read-text-file", "fs:allow-resource-read-recursive"]
```

https://v2.tauri.app/develop/resources/

- `$APPDATA/*` matches direct children only; use `$APPDATA/**/*` for depth. `deny` beats `allow`. `fs:scope` sets a global scope. https://v2.tauri.app/plugin/file-system/
- Unix dotfolders (`.ssh`) are skipped by wildcards: give the full path or a glob after the dot component, or set `plugins.fs.requireLiteralLeadingDot: false`. https://v2.tauri.app/plugin/file-system/
- File handles: always `close()` after `create()` / `open()`. `create` truncates. `open` is read-only by default; `write: true` truncates on each `write()` unless `append: true`; `createNew` fails if the file exists. https://v2.tauri.app/plugin/file-system/
- `remove` fails on a missing path and needs `recursive: true` for non-empty dirs. `copyFile` and `rename` take `fromPathBaseDir` and `toPathBaseDir` separately. `stat` follows symlinks (and errors outside scope), `lstat` does not. https://v2.tauri.app/plugin/file-system/
- `watch` (debounced) and `watchImmediate` need the `watch` feature; directory watching is non-recursive unless `recursive: true`. https://v2.tauri.app/plugin/file-system/
- Mobile: Android audio, cache, documents, downloads, picture, public and video dirs need `READ_EXTERNAL_STORAGE` / `WRITE_EXTERNAL_STORAGE` in `AndroidManifest.xml`. iOS needs `src-tauri/gen/apple/PrivacyInfo.xcprivacy` declaring `NSPrivacyAccessedAPICategoryFileTimestamp` with reason `C617.1`. https://v2.tauri.app/plugin/file-system/
- persisted-scope keeps runtime-granted fs and asset scopes across restarts. Register it AFTER fs, or it silently does nothing (dev prints a warning). https://v2.tauri.app/plugin/persisted-scope/

## dialog

- File dialogs return file paths on desktop, `file://` URIs on iOS and content URIs on Android. The fs plugin accepts all three. https://v2.tauri.app/plugin/dialog/
- JS: `ask` (Yes/No), `confirm` (Ok/Cancel), `message`, `open({ multiple, directory })`, `save({ filters })`. Rust `blocking_pick_file()` returns `None` when the user cancels; non-blocking forms are `pick_file(cb)` and `show(cb)`. https://v2.tauri.app/plugin/dialog/

## opener

- Opens URLs and files with the default or a named program, and reveals files in the file manager. https://v2.tauri.app/plugin/opener/

```javascript
import { openPath, openUrl } from '@tauri-apps/plugin-opener';
await openPath('C:/path/to/file', 'vlc');
await openUrl('https://tauri.app');
```

```json
{ "identifier": "opener:allow-open-url", "allow": [{ "url": "https://tauri.app" }, { "url": "custom:*" }] }
```

https://v2.tauri.app/plugin/opener/

- Custom protocol URLs in the scope must be registered with the OS. https://v2.tauri.app/plugin/opener/

## shell

- Spawns processes; `open` moved to opener. JS refers to the scope `name`, not the program. https://v2.tauri.app/plugin/shell/

```json
{ "identifier": "shell:allow-execute", "allow": [{ "name": "exec-sh", "cmd": "sh",
  "args": ["-c", { "validator": "\\S+" }], "sidecar": false }] }
```

```js
import { Command } from '@tauri-apps/plugin-shell';
await Command.create('exec-sh', ['-c', "echo 'Hello World!'"]).execute();
```

https://v2.tauri.app/plugin/shell/

- Rust: `app.shell().command("echo").args([...]).output().await`. https://v2.tauri.app/plugin/shell/

## http, upload, websocket

- http: a Fetch-compatible `fetch` from `@tauri-apps/plugin-http`; Rust re-exports `reqwest`. Allowed URLs are configured in the `http:default` scope (with `allow` and `deny` lists): https://v2.tauri.app/plugin/http-client/

```json
{ "identifier": "http:default", "allow": [{ "url": "https://*.tauri.app" }],
  "deny": [{ "url": "https://private.tauri.app" }] }
```

https://v2.tauri.app/plugin/http-client/

- Forbidden request headers are dropped unless the `unsafe-headers` feature is on. https://v2.tauri.app/plugin/http-client/
- upload: `upload()` sends the raw file as the body (not multipart), default `POST`. `download()` defaults to `GET`, needs an existing parent dir, overwrites, and leaves partial files on failure. https://v2.tauri.app/plugin/upload/
- upload progress: `progress` is the last chunk, `progressTotal` the running total, `total` for downloads comes from `Content-Length` and is `0` without it. https://v2.tauri.app/plugin/upload/
- Relative paths resolve against the working dir, which differs between `tauri dev` and the bundle: build absolute ones, `join(await appDataDir(), 'file.txt')`. https://v2.tauri.app/plugin/upload/
- websocket: a Rust-side WebSocket driven from JS (`WebSocket.connect`, `addListener`, `send`, `disconnect`). https://v2.tauri.app/plugin/websocket/

## sql, store, stronghold

- sql wraps sqlx; pick a driver feature when installing: `cargo add tauri-plugin-sql --features sqlite` (or `mysql`, `postgres`). https://v2.tauri.app/plugin/sql/
- `Database.load('sqlite:test.db')` is relative to `AppConfig`. Placeholders: `$1` for SQLite and Postgres, `?` for MySQL. Writes need `sql:allow-execute` besides `sql:default`. https://v2.tauri.app/plugin/sql/
- Migrations are Rust `Migration { version, description, sql, kind: MigrationKind::Up }` passed to `.add_migrations(url, migrations)`. They run when the URL is in `plugins.sql.preload` or when `Database.load()` runs, all in one transaction that rolls back on failure. https://v2.tauri.app/plugin/sql/
- MySQL/Postgres connection strings take the form `mysql://user:password@host/test`. https://v2.tauri.app/plugin/sql/
- store: `load('store.json', { autoSave: false })`; options are ignored if that store is already open. Saves on graceful exit, on `save()`, or after a debounce (100 ms by default with `autoSave`). `new LazyStore('settings.json')` loads on first use. https://v2.tauri.app/plugin/store/
- store from Rust: `app.store("store.json")?` shares the same instance as JS; values are `serde_json::Value`. https://v2.tauri.app/plugin/store/
- stronghold: add `[profile.dev.package.scrypt] opt-level = 3` (workaround for an upstream bug). The password hasher must return exactly 32 bytes; default `Builder::with_argon2(&salt_path)` with the salt in `app_local_data_dir()`. Values are byte arrays; call `stronghold.save()` to persist. https://v2.tauri.app/plugin/stronghold/

## log

- `tauri_plugin_log::Builder::new().build()`; Rust logs through the `log` crate. Defaults: stdout plus a file in the app log dir, every level, UTC timestamps. https://v2.tauri.app/plugin/logging/
- Pitfall: when the file hits max size it is discarded by default. Keep history with `rotation_strategy(RotationStrategy::KeepAll)` and size it with `max_file_size(bytes)`. https://v2.tauri.app/plugin/logging/
- Filter with `level(log::LevelFilter::Info)`, `level_for("my_crate::commands", Trace)` or `filter(...)`. Local time: `timezone_strategy(TimezoneStrategy::UseLocal)`. `clear_targets()` removes the defaults. https://v2.tauri.app/plugin/logging/
- Show Rust logs in devtools: add `TargetKind::Webview` and call `attachConsole()` in JS. https://v2.tauri.app/plugin/logging/
