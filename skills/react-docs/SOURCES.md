## Contradictions between pages

- Concurrent Transitions: the useTransition and startTransition pages say ongoing Transitions are batched together. The 19.3 release notes say unrelated Transitions render independently. The skill states the 19.3 behavior and advises not to rely on batching.
- Fragment refs and `use(browser())`: the Fragment and browser pages show canary sandboxes. The 19.3 release notes ship both. The skill treats them as part of 19.3.
- Ref guard in an Effect: the exhaustive-deps page offers a ref guard for a run-once side effect. The Synchronizing with Effects page forbids a ref guard to hide the development double run. The skill keeps the guard only for side effects that must never repeat.
- `useLayoutEffect` on the server: its reference page documents a "does nothing on the server" warning. The 19 upgrade guide says the layout effect SSR warning was removed. The skill only states that it does nothing on the server.
- `renderToStaticMarkup` points interactive apps to `renderToString` with `hydrateRoot`. The renderToString page calls it legacy and recommends the streaming APIs. The skill follows the renderToString page.
- `eslint-plugin-react-hooks` presets: the 19.2 release notes name `recommended` (flat) and `recommended-legacy`. The React Compiler 1.0 post names `reactHooks.configs.flat.recommended` and `plugin:react-hooks/recommended`. The skill quotes the later post.
- The config lint page lists only `'infer'` and `'all'` for `compilationMode`. The compilationMode page lists 4 values. The skill follows the compilationMode page.
- The react-dom/client page still states Internet Explorer 9 support. The skill omits it as outdated.
